# Hash Table in C - Multi-Type Support


A generic, production-ready hash table implementation in C that supports **multiple primitive data types** including integers, floats, doubles, characters, and strings.

## ✨ Features

- ✅ **Multi-type support** - Store `int`, `float`, `double`, `char`, and `string` values
- ✅ **Dynamic resizing** - Automatically grows when load factor exceeds 0.5
- ✅ **Double hashing** - Efficient collision resolution with two hash functions
- ✅ **Memory safe** - Proper memory allocation and deallocation
- ✅ **Type-aware** - Compile-time and runtime type checking
- ✅ **Simple API** - Easy-to-use interface for all operations
- ✅ **Tested** - Comprehensive test suite included
